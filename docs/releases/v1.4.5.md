# Release Notes - v1.4.5

> **Release Version**: `v1.4.5`  
> **Release Date**: 2026-11-13  
> **Status**: Production Release  
> **Package**: [`mcp-fingerprints`](https://pypi.org/project/mcp-fingerprints/)

---

## Overview & Highlights

`v1.4.5` expands the passport catalog (6,033 passports in `passports.json.gz`, 5,862 individual passport files in `data/fingerprints/`) and delivers comprehensive code quality, reliability, security, and packaging hardening without altering public functionality:

1. **Runtime & Data Integrity Fixes**
   - Fixed `.json.gz` dictionary iteration in `mcp_fingerprints.reporter.iter_passports()`.
   - Fixed `by_purl` lookup normalization in `mcp_fingerprints.index.FingerprintFastIndex.find_package_by_hint_or_alias()`.
   - Fixed `mcp_fingerprints.db_engine.EphemeralDBEngine.find_by_hash()` to query canonical `"versions"` alongside legacy `"version_fingerprints"`.
   - Guarded scoped npm/npx directory traversal in `mcp_fingerprints.config_scanner` with `is_dir()`.
   - Replaced lexicographical version sorting with `packaging.version.parse` (with `InvalidVersion` fallback) in `sbom_exporter.py` and `crawler/__init__.py`.

2. **Security & Subprocess Hardening**
   - Restored verified TLS (`ssl.create_default_context()`) and removed module-level `logging.basicConfig()` pollution in `synchronizer.py`.
   - Unified `McpStdioProber` (`prober.py`) and `detect_mcp_stdio` (`detector.py`) onto `sanitize_environment()` and non-blocking daemon-thread queue I/O from `runtime_sandbox.py`.

3. **Modular Architecture & Packaging**
   - Decomposed `ast_parser.py` into `src/mcp_fingerprints/ast_parser/` with per-language modules and full backward-compatible re-exports.
   - Clarified `validator.py` → `mcp_classifier.py` and `go_crawler.py` → `crawler/pkg_go_dev.py` with backward-compatible shims.
   - Moved `playwright` / `pytest-playwright` to `[project.optional-dependencies] dev` and added `numpy>=1.26.0` to `semantic` in `pyproject.toml`.
   - Fixed `from src.mcp_fingerprints...` wheel import errors across reindexers and tests.
