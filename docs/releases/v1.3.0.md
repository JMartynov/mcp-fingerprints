# Release Notes - v1.3.0

> **Release Version**: `v1.3.0`  
> **Release Date**: 2026-11-01  
> **Status**: Production Release  
> **Package**: [`mcp-fingerprints`](https://pypi.org/project/mcp-fingerprints/)

## 🌟 Overview & Highlights

`v1.3.0` is a major capability release delivering full web catalog tool signature integration, automated Playwright headless browser CI workflows, PyPI packaging verification, and extensive tool extraction across 6 parallel Google Jules waves.

---

## 🚀 Key Improvements & Features

### 1. Web App Tool Signature Bridge & Catalog Normalizer (Task W2)
- **74,793 Tool Signatures Unlocked**: Updated `getVersionData()` in `web/app.js` to normalize tool resolution from `versions[].tool_signatures`, allowing 3,998 MCP servers with existing signatures to render tool cards, badges, and parameter inspection drawers.
- **Deep Parameter & Tool Search**: Enhanced `render()` in `web/app.js` to perform case-insensitive keyword searches across tool names, parameter schemas, and descriptions.
- **Catalog Normalizer Utility**: Authored `scripts/normalize_catalog_tools.py` and test suite `tests/test_web_catalog_normalizer.py` (4 of 4 passed).

### 2. Automated Playwright Headless Browser CI (Task CI1 & Task W1)
- **GitHub Actions E2E Pipeline**: Created `.github/workflows/e2e.yml` running automated Chromium Playwright tests with test failure artifact uploading.
- **E2E Test Suite**: Authored `tests/test_web_pwa_e2e.py` validating offline PWA service worker caching, windowed DOM virtualization memory recycling, and search responsiveness.
- **Workflow Syntax Validation**: Authored `tests/test_github_workflows_syntax.py` ensuring pipeline definition integrity.

### 3. Packaging & Daily Sync CI Verification (Task C1)
- **Distribution Manifest**: Added `MANIFEST.in` ensuring docs, web catalog assets, and canonical schemas are packaged cleanly into wheels and sdists.
- **CI Resilience Tests**: Added `tests/test_packaging_and_sync_ci.py` validating build generation and error resilience during daily registry crawling.

### 4. Scaled Tool Extraction Across 6 Waves
- **Over 80+ Top MCP Servers Enriched**: Extracted AST tool schemas and recomputed `toolset_canonical_hash` digests for priority servers across:
  - **Wave 1**: Google Contacts, Docs, Drive, Gmail, Flights Deals, WSL-C.
  - **Wave 2**: Docker, Cloudflare Workers AI/Pro, Neon Gateway, Playwright, GitHub, Filesystem, Google Calendar/Maps/Search Console.
  - **Wave 3**: Agent OS (+124 tools), JetBrains Debugger (+50 tools), GitLab (+27 tools), Google Measurement, Fetch, etc.
  - **Wave 4**: PowerApps Canvas Authoring (+232 tools), FluentUI (+20 tools).
  - **Wave 5**: AgentNexus, Synapse, BagOS, Derbent, SSH-MCP, etc. (15 servers).
  - **Wave 6**: +39,286 lines of rich tool schemas across 36 servers.
- **Master Datasets Rebundled**: Updated `passports.json.gz` (16.12 MB) and `web/catalog.json` (97.34 MB).
