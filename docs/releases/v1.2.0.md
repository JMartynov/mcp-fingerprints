## 🌟 Overview & Highlights

`v1.2.0` represents a milestone release delivering full system-wide hardening, enterprise resilience, and deep architectural alignment across all 5 core pillars of the project:
1. **Pillar 1: Data Pipeline & Registry Link Enrichment**: Populated upstream repository links for 82 passports via PyPI/NPM registry APIs (`hub_resolver.py`), converted third-party hub URLs to direct GitHub sources, and flagged 51 dead/unreachable repositories with `status: "unreachable_or_private"`.
2. **Pillar 2: Web App PWA & Virtualization Overhaul**: Overhauled PWA service worker (`web/sw.js`) to transition catalog caching from upfront pre-caching to an on-demand stale-while-revalidate strategy. Implemented windowed DOM recycling in `web/app.js` with capped memory footprints and added responsive parameter table horizontal scroll wrappers for mobile viewports.
3. **Pillar 3 & 4: Core Toolset Hardening & Parser Resilience**: Added `max_depth=15` cyclic `$ref` recursion limiter to `openapi_parser.py`, line-by-line prefix log filtering in `prober.py` to seamlessly isolate JSON-RPC responses from interleaved plaintext stdout logs, and 10MB subprocess buffer caps in `runtime_sandbox.py`. Authored new network fault injection tests (`tests/test_fault_injection.py`).
4. **Pillar 5: Documentation & Specification Parity**: Documented all 7 missing CLI commands, 3 Python SDK exports (`McpIdentifier`, `scan_local_configs`, `scan_config_file`), and extended schema fields (`remote_endpoint`, `auth_type`, `headers_schema`, `annotations`) in `docs/SPECIFICATION.md` and `README.md`.
5. **Google Jules Mode 2 Review**: Fully audited and verified across Waves 1–4 by Google Jules (Session `8394579379504931713`, Issue #92) with 100% test pass rate (505 tests passed, 0 failed).

## 🚀 Key Improvements & Changes

### 1. Data Pipeline & Passport Knowledge Base
- **Upstream Repository Resolution**: Automated queries against PyPI and NPM registry APIs populated genuine GitHub source URLs for 82 MCP servers.
- **Dead/Private Status Tagging**: Tagged unreachable upstream repositories with `status: "unreachable_or_private"` in passport metadata to preserve forensic provenance while signaling availability status.
- **Re-bundled Master Datasets**: Updated `passports.json.gz` (15.94 MB) and `web/catalog.json` (compacted single-line JSON) to reflect all new URLs and status flags.

### 2. Web Catalog PWA & DOM Virtualization
- **On-Demand Stale-While-Revalidate**: Service worker (`web/sw.js`) no longer blocks offline activation on pre-caching large catalog assets, dynamically caching catalog requests with background updates.
- **Windowed DOM Recycling**: `web/app.js` renders only active visible items (`getVisibleRange`), dynamically recycling DOM nodes during fast scrolling to eliminate browser tab memory bloat.
- **Mobile Viewport Guards**: Parameter and tool schema tables now wrap cleanly in responsive horizontal scroll containers (`@media (max-width: 600px)`).

### 3. Core Toolset & Parser Hardening
- **Cyclic `$ref` Recursion Protection**: `openapi_parser.py` implements a recursion depth limiter (`max_depth=15`) protecting against circular OpenAPI schema references.
- **Robust JSON-RPC Log Parsing**: `prober.py` filters non-JSON log lines prefixed to stdout streams, ensuring MCP handshakes succeed even when servers log directly to stdout.
- **Subprocess OOM Protection**: 10MB buffer caps on read operations in `runtime_sandbox.py` and `prober.py`.
- **Fault Injection Test Suite**: New test suite in `tests/test_fault_injection.py` validating mid-stream network drops and malformed JSON-RPC payloads under strict offline socket mocking.

### 4. Documentation & Schema Parity
- **Full CLI Command Coverage**: Documented `export-passports`, `inspect-passport`, `diff-passports`, `probe`, `verify-sandbox`, `sync-hub`, and `doctor` in `docs/SPECIFICATION.md` and `README.md`.
- **SDK Exports**: Fully documented `McpIdentifier`, `scan_local_configs`, and `scan_config_file`.
- **Schema Alignment**: Clarified `remote_endpoint`, `auth_type`, `headers_schema`, and `annotations` attributes.
