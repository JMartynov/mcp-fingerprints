# Daily Web Card Quality Audits

This directory contains automated daily reports produced by the scheduled inspection agent defined in [task_82_daily_web_cards_and_updates_audit_scenario.md](../../tasks/task_82_daily_web_cards_and_updates_audit_scenario.md).

## Structure
- [master_audit_summary.md](master_audit_summary.md): Consolidated historical ledger across all daily inspection runs.
- `runs/`: Daily inspection markdown reports named by UTC date (`runs/YYYY-MM-DD.md`).
